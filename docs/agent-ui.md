# 问答侧栏与过程展示

现有页面继续使用 `app.js`、原有 hash 路由与 `data/archive.js`。问答侧栏由独立的 `agent-widget.js` / `agent-widget.css` 加载，公开连接配置位于 `agent-config.js`。

公开配置中的 `apiBase` 已指向独立的 Cloudflare Worker；将它设为空可暂时断开问答模块，静态页面仍可正常浏览和搜索。服务尚未配置时，侧栏会说明原因。生产环境不会自动生成模拟回答，不需要在浏览器中填写 OpenAI key。

## 立即查看本地流程

运行数据构建和本地预览：

```sh
npm run agent:build
npm run agent:preview
```

打开终端打印的 `http://127.0.0.1:4174`，点击右下角“问档案”，选择示例问题并提问。预览只监听本机，使用真实的索引检索、私有 KV 和 SQLite 预算流程；模型文本为本地模拟，页面始终显示“本地流程演示 / 回答为模拟 / 不调用 OpenAI”。无需填写密钥或访问口令。

预览服务器仅在其响应的 `agent-config.js` 中注入演示连接参数，不改写或打包生产配置。前端只在本机页面且 API 同源时接受演示参数。

## 可以看到什么

每次提问会生成独立的“本次查阅流程”，通过服务端 SSE `trace` 事件更新：

1. 解析问题中的时间和主题。
2. 关键词检索。
3. 时间索引过滤。
4. 主题索引过滤。
5. 合并排序。
6. 选取原文证据。
7. 核对输入 tokens。
8. 预留今日预算。
9. 依据证据生成回答。

面板只显示安全的数量、时间范围、已脱敏的节点 ID / 标题和预算数字，不显示提示词、原文全文、访问凭证或 OpenAI key。服务未执行的阶段显示“本次未执行”，中断的阶段会单独标记。

生成中的文本以纯文本流式展示。完成后显示服务器核验的来源链接；只允许站内档案路由，禁止模型提供的任意 URL。来源可回到项目、研究问题、资料摘要或证据弹窗。证据路由 `#/evidence/m00008` 支持直接打开和重复点击。

“新对话”清空本页问答记录。历史对话只保存在内存，不写入 localStorage；每次请求最多携带 6 条消息，每条不超过 3,000 字、合计不超过 6,000 字。“停止”会取消浏览器请求，已发出的模型调用仍可能计费，后端会保守结算。

## 前端验收

先启动独立的本地预览，再运行：

```sh
node agent/tests/widget-browser.mjs
```

脚本使用 Playwright 的独立无登录浏览器环境，检查桌面和手机布局、流程事件、引用链接、停止、新对话、预算错误、原站路由、搜索快捷键和 HTML / 非站内链接的拒绝。截图保存在忽略的 `.local/agent-qa/`，不会进入静态构建。

可通过 `AGENT_PREVIEW_URL` 指定测试预览地址；建议测试使用独立端口，避免占用用户演示页的每日限额。浏览器未安装时可运行 `npx playwright install chromium`，或用 `AGENT_BROWSER_EXECUTABLE` 指定独立 Chromium 的可执行文件。
