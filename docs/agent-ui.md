# 问答侧栏与过程展示

现有页面继续使用 `app.js`、原有 hash 路由与 `data/archive.js`。问答侧栏由独立的 `agent-widget.js` / `agent-widget.css` 加载，公开连接配置位于 `agent-config.js`。

公开配置中的 `apiBase` 已指向独立的 Cloudflare Worker；将它设为空可暂时断开问答模块，静态页面仍可正常浏览和搜索。服务尚未配置时，侧栏会说明原因。生产环境不会自动生成模拟回答，不需要在浏览器中填写 OpenAI key。

当前使用 `authMode: 'public'`，服务就绪后可以直接提问，不显示访问口令输入框，也不发送 `Authorization`。每日 1 美元额度由所有访客共享，单 IP 次数、并发与预算拦截继续由后端执行。前端仍兼容 `token` 和 `turnstile` 两种可选模式，公开模式不依赖演示口令或任何前端密钥。

## 立即查看本地流程

运行数据构建和本地预览：

```sh
npm run agent:build
npm run agent:preview
```

打开终端打印的 `http://127.0.0.1:4174`，点击右下角“问档案”，选择示例问题并提问。预览只监听本机，使用真实的索引检索、私有 KV 和 SQLite 预算流程；模型文本为本地模拟，页面始终显示“本地流程演示 / 回答为模拟 / 不调用 OpenAI”。无需填写密钥或访问口令。

预览服务器仅在其响应的 `agent-config.js` 中注入演示连接参数，不改写或打包生产配置。前端只在本机页面且 API 同源时接受演示参数。

## 可以看到什么

每次提问会生成独立的“本次查阅流程”，通过服务端 SSE `trace` 事件更新：

1. 解析问题中的时间和主题。
2. 关键词检索。
3. 时间索引过滤。
4. 主题索引过滤。
5. 合并排序。
6. 选取原文证据。
7. 核对输入 tokens。
8. 预留今日预算。
9. 依据证据生成回答。

面板只显示安全的数量、时间范围、已脱敏的节点 ID / 标题和预算数字，不显示提示词、原文全文、访问凭证或 OpenAI key。服务未执行的阶段显示“本次未执行”，中断的阶段会单独标记。

生成中的文本以纯文本流式展示；完成后，助手回答使用本地固定版本的 marked 18.1.3 解析 Markdown，再通过 DOMPurify 3.4.17 的严格白名单清理并插入 DOM。用户问题始终为纯文本。支持标题、列表、表格、代码块、引用和安全链接；表格与长代码可横向滚动。原始 HTML 显示为字面文本，远程图片降为说明文字，不会加载外部图片。Markdown 链接只接受 HTTP、HTTPS 与 mailto，拒绝 javascript、data 等方案。

解析和清理库打包在 `assets/vendor/agent-markdown.min.js`，随静态站点部署，运行时不加载第三方 CDN；完整许可证保留在同目录。源码入口为 `agent/markdown.mjs`。需要升级依赖时，先审查版本，再运行 `npm ci` 和 `npm run agent:vendor` 重建。静态构建会检查本地 bundle 是否存在，避免上线缺少解析器。

完成后另显示服务器核验的来源链接；该来源区只允许站内档案路由。来源可回到项目、研究问题、资料摘要或证据弹窗。证据路由 `#/evidence/m00008` 支持直接打开和重复点击。

回答中的 `[m06905]`、`[project:knowledge-complexity]` 等标记，会在安全渲染完成后，依据服务端本次已核验的引用列表转换为可读链接。未知标记、代码块和已有 Markdown 链接中的标记不会被替换。正文引用与底部来源共用导航逻辑。

点击来源时保留当前对话 DOM、历史、原页面 hash 和回答滚动位置；来源页提供明确的“← 返回问答”按钮。原文证据使用原站原生弹窗，因此返回按钮也放在证据弹窗内部。返回会回到原页面并重新打开原回答，恢复滚动位置。新对话会清除返回状态，普通站内导航不会误显示返回入口。

“新对话”清空本页问答记录。历史对话只保存在内存，不写入 localStorage；每次请求最多携带 6 条消息，每条不超过 3,000 字、合计不超过 6,000 字。“停止”会取消浏览器请求，已发出的模型调用仍可能计费，后端会保守结算。

## 前端验收

先启动独立的本地预览，再运行：

```sh
node agent/tests/widget-browser.mjs
node agent/tests/widget-markdown-browser.mjs
```

脚本使用 Playwright 的独立无登录浏览器环境，检查公开模式无口令和无 Authorization 请求、桌面和手机布局、流程事件、引用链接、停止、新对话、预算错误、原站路由、搜索快捷键、Markdown 标题／列表／表格／代码／引用、中文流式边界和恶意 HTML／链接／图片的拒绝。截图保存在忽略的 `.local/agent-qa/`，不会进入静态构建。

可通过 `AGENT_PREVIEW_URL` 指定测试预览地址；建议测试使用独立端口，避免占用用户演示页的每日限额。浏览器未安装时可运行 `npx playwright install chromium`，或用 `AGENT_BROWSER_EXECUTABLE` 指定独立 Chromium 的可执行文件。
