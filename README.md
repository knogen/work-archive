# 诺知 · 工作档案

将多年群聊整理为围绕成果与问题的前端档案。资料覆盖 **2018-10-07 至 2026-05-06**。

- **项目专题**：10 个跨年专题，记录已有工作、项目里程碑、待续问题及代表材料。
- **时间线**：156 个精选节点，可按年份、专题、交付状态和关键词筛选；小项目在这里单独保留。
- **待续研究**：38 个问题，包含做过的尝试、最后已知状态、建议验证步骤与证据；支持复制或下载 Deep Research 续研资料包。
- **资料库**：220 组材料，折叠重复发送与修订版本；25 份代表附件随网站收录，其他文件明确标记缺失或未收录。
- **原文证据**：1,110 条经过筛选与脱敏的原文摘录，保留消息 ID、发送人、原始时间和原文件行号。

## 本地查看

无需安装依赖，Node.js 20 或更高版本即可。

```sh
npm start
```

打开终端显示的 `http://127.0.0.1:4173`。也可以直接打开 `index.html`；复制到剪贴板功能可能受 `file://` 浏览器权限限制，Markdown 下载仍可使用。

```sh
npm run check
npm run build
```

构建产物位于 `dist/`。站点使用相对资源路径和 hash 路由，可部署到 GitHub Pages 子目录或任意静态托管服务。仓库不会自动开启公开网站部署；发布范围由仓库所有者决定。

## 内容与维护

`data/archive.json` 是网站数据源；`data/archive.js` 是可直接在本地打开页面的浏览器副本。修改 JSON 后执行 `npm run data`，或由 `npm run build` 自动同步。

```text
index.html / styles.css / app.js   前端，无运行时依赖
data/archive.json                 结构化归档数据
data/archive.js                   浏览器数据副本
assets/                           经过筛选的代表附件
editorial/analysis-1..3.json        三个时间段的内容整理底稿
editorial/question-audit.json      跨期问题闭环审查
scripts/                          本地服务、检查、构建、数据生成
```

原始整理采用三个 subagent 分时段覆盖：2018—2021-05、2021-05—2022-08、2022-08—2026-05。主流程归并跨年专题，另对早期问题是否已在后期解决作交叉审查。底稿不是最终网站状态；网站中的问题合并与纠正以 `data/archive.json` 为准。

### 从原导出重新生成

完整群聊原文、全量媒体与解析中间文件只在本地保留，未推送至此仓库。数据处理不调用外部 API：

```sh
python scripts/import_export.py --source /path/to/export --output .local/analysis
python scripts/assemble.py --analysis .local/analysis --source /path/to/export
npm run check
npm run build
```

`import_export.py` 生成消息、资源与附件索引。首次归档的三个分析底稿与跨期审计从 `editorial/` 读取；导入新记录后必须先更新底稿、核对 ID 与事实，再运行组装。消息 ID 按导出顺序分配，换用不同导出文件时必须重新对齐，不能假设旧 ID 自动稳定。源文件 SHA-256 保存在 `meta.sourceSha256`，用于检查引用对应的资料版本。

新增或修订一项工作时，请保留：事实日期、状态范围、至少一条原文引用，以及是否存在缺失附件。续研建议必须与已经做过的实验分开，问题解决后应补上验证结果与证据，而非只删除问题。

## 资料边界

导出目录自述 **9,917 条消息**，按时间头解析得到 **10,011 个条目**，差异包括合并转发中嵌套的历史消息。后者不代表顶层消息总数，网站不以此声称新增工作量。

资源清单有 370 条可用、372 条缺失、976 条加密记录；这是资源记录状态，不是独立文件数。115 条语音未转写。未解密图片、缺失文档和未转写语音未被用于推断内容结论。

“最近可读副本”不等于“最终定稿”；“申请提交”不等于“专利授权”；“未见后续答案”不等于现实中尚未解决。历史工作记录中的科学结论和数字没有在本次重新跑实验验证。第三方论文和书籍只保留群聊索引，不在仓库重新分发全文。

此仓库包含经过选择的工作摘录与研究材料。完整原文和生活口令等非工作敏感信息不随项目上传；后续导入仍需检查证据摘录和附件中的敏感内容。
